# ForClaudeCredits

Experiments with Claude Code cloud sessions.

## [explainer-video/](explainer-video/) — "Make videos with code"

A 60-second motion-graphics explainer with music, made entirely from code, with no paid AI tools:

- **Visuals:** HTML + CSS + [GSAP](https://gsap.com) animation, rendered to MP4 by [HyperFrames](https://github.com/heygen-com/hyperframes) (open source, Apache 2.0)
- **Music:** an original track generated by a small JavaScript synthesizer ([`music/compose.mjs`](explainer-video/music/compose.mjs))
- **Output:** [`explainer-video/renders/make-videos-with-code.mp4`](explainer-video/renders/make-videos-with-code.mp4) (1920×1080, 30 fps)

[![Open in GitHub Codespaces](https://github.com/codespaces/badge.svg)](https://codespaces.new/eladsch1987/ForClaudeCredits?ref=ccr-f1f2de7d-e8txg3)

**Edit it in your browser, no download:** click the button above, then **Create codespace**. After a few minutes of one-time setup, HyperFrames Studio opens in a new tab. Details in [TWEAKING.md](explainer-video/TWEAKING.md#in-your-browser-with-github-codespaces-no-download).

Each scene is its own file in [`compositions/`](explainer-video/compositions/), so you can edit it visually in HyperFrames Studio (`npx hyperframes preview`) or in any text editor. See [explainer-video/TWEAKING.md](explainer-video/TWEAKING.md) to change text, colors, timing or music and re-render.
