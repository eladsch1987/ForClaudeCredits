# How to tweak this video

Everything in this video is code: the visuals are a web page (`index.html`) and the music is a small script (`music/compose.mjs`). To change anything, edit the text, then re-render.

## The 3 commands you need

Run these from inside the `explainer-video` folder. You need Node.js 22+ and FFmpeg installed; both are free.

```bash
npx hyperframes preview     # live preview in your browser (edit -> it refreshes)
node music/compose.mjs      # rebuild the music after changing it
npx hyperframes render -q high -o renders/make-videos-with-code.mp4   # export the MP4
```

`npx hyperframes check` catches mistakes such as overlapping text or low contrast. Run it before rendering.

## Common changes

| I want to… | Do this |
|---|---|
| Change the colors | Edit the `default` hex values at the top of `index.html` (`violet`, `pink`, `yellow`, `mint`, …). Every scene uses these. |
| Change the opening headline or final line | Edit `headline` / `cta` at the top of `index.html`. You can also do it at render time without editing: `npx hyperframes render --variables '{"headline":"Make ads","cta":"Try it!"}'` |
| Change any other text | Find the sentence in `index.html` and retype it. Text is plain HTML. |
| Make a scene longer or shorter | Change `data-start` / `data-duration` on that scene's `<section>`, and shift the following scenes (plus the matching `wipe`). The animations inside a scene follow it automatically. |
| Make the music faster / slower | Change `BPM` in `music/compose.mjs` **and** `BEAT` in `index.html` (BEAT = 60 / BPM), then re-run `node music/compose.mjs`. |
| Change the melody or chords | Edit `MELODY` / `CHORDS` in `music/compose.mjs` (MIDI note numbers: 60 = middle C). |
| Turn instruments on/off per section | Edit `layersFor()` in `music/compose.mjs`. |
| Make it vertical (9:16) for Reels/TikTok | Ask Claude: "Make a 9:16 version of this video". The layout needs rearranging, not just resizing. |

## Or just ask Claude

The easiest way is to open this repo in Claude Code and describe the change in plain words:

- "Make the title bigger and the background darker"
- "Replace the toolkit scene with three tips about lighting"
- "Make the music calmer, like lo-fi"
- "Render a 15-second cut of just the intro and outro"

Claude edits the files, runs `npx hyperframes check`, and re-renders.

```
│   ├── fonts/            ← Poppins + JetBrains Mono (free, SIL Open Font License)

```

## Scene map (60 s, 120 BPM — one bar = 2 s)

| Time | Scene | Music |
|---|---|---|
| 0–6 s | Hook: "Make videos with code?" | Beat + plucks, build-up, drop at 6 s |
| 6–14 s | The trick: a video is a web page that moves | Full groove |
| 14–22 s | Free tools (HyperFrames, Remotion, Chrome + FFmpeg) | Full groove + melody |
| 22–32 s | How it works, in 4 steps | Full groove + melody |
| 32–40 s | Even the music is code | Drums → + bass → + chords → + melody |
| 40–50 s | Tweak anything | Full groove |
| 50–56 s | Skills you need | Groove, build-up at 54 s |
| 56–60 s | Your turn | Final drop + ending hit |

## Costs

All of this is free and runs on your own computer (or a Claude Code cloud session). There are no API keys, paid AI generators, or stock music. HyperFrames also offers paid extras like cloud rendering and HeyGen voices; this project doesn't use them.
